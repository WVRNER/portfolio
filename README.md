# Nima Hosseini (@wvrner) — Infrastructure & Cloud Engineer Portfolio

Modern, high-performance personal engineering portfolio built for Nima Hosseini (@wvrner), Infrastructure & Cloud Engineer.

- **Persistent Ambient Cloud Mesh (`hero-canvas.js`)**:
  - Full-viewport ambient distributed cloud topology network with active telemetry data packets, organic breathing aurora, dynamic cursor magnetic spotlight, and continuous parallax scroll depth.
  - Sized persistently to the viewport so the animation never cuts off or terminates abruptly on scroll.
- **Next-Gen VisionOS Glass Navigation Island**:
  - Specular glass island with multi-layered frosted blur (`backdrop-filter: blur(28px) saturate(210%)`), custom Monogram "W" prism logo, live telemetry beacon (`SYS // LIVE`), dynamic fluid magnetic sliding pill indicator, floating CV quick-popover drawer, and haptic theme switcher.
- **Neat Architecture & Systems Showcase**:
  - Bento-style engineering cards covering Multi-Region Cloud Topologies (99.99% SLA), Infrastructure as Code (IaC with zero drift), Container Orchestration & GitOps (Kubernetes & ArgoCD), and Full-Stack SRE Observability.
- **Interactive Cloud Terminal (`nimactl`)**:
  - Interactive simulated CLI console featuring switchable tabs for cluster health checks, Terraform IaC state verification, and global mTLS service mesh inspection.
- **Rebuilt Unique & Modern Footer**:
  - Monolithic blueprint card with engineering corner crosshairs (`+`) and geographical coordinates (`NYC // 40.7128° N, 74.0060° W`).
  - Live digital world clock displaying real-time Local and UTC ticking time.
  - Direct Comms box with 1-click clipboard copy for `wvrner@outlook.com` and dynamic confirmation tooltip.
  - Direct links to GitHub ([@wvrner](https://github.com/wvrner)), LinkedIn ([@wvrner](https://linkedin.com/in/wvrner)), and Email ([wvrner@outlook.com](mailto:wvrner@outlook.com)).
  - Giant typographic horizon watermark (`WVRNER`).
  - Back-to-top floating trigger.
- **Light & Dark Mode**:
  - Dynamic theme persistence via `localStorage` with automated system preference detection.

## Quick Start

Open `index.html` in any modern web browser:
```bash
open /tmp/jay-park-portfolio/index.html
```

Or serve locally with any static HTTP server:
```bash
python3 -m http.server 8000 --directory /tmp/jay-park-portfolio
```
