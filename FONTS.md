# Typography System & Font Licensing

This project uses an open-source, freely licensed typography system optimized for web performance and zero-dependency self-hosting via `next/font/google`.

---

## 1. Primary Display Typeface: Manrope
* **Role:** Primary Display Typography (Hero headings, section titles, monumental disciplines, campaign quotes).
* **Classification:** Modern Geometric-Humanist Sans-Serif (Swiss-influenced, semi-rounded geometric architecture similar in visual spirit to GT Walsheim, with open counters and balanced lowercase forms).
* **Designer:** Mikhail Sharanda with additions by Mirtha Type.
* **License:** **SIL Open Font License, Version 1.1 (OFL-1.1)**
  * Permitted: Free for personal and commercial use, web embedding, bundling, and distribution.
  * Official Source: [Google Fonts / Manrope](https://fonts.google.com/specimen/Manrope) & [GitHub / MikhailSharanda/manrope](https://github.com/MikhailSharanda/manrope)
* **Weights In Use:** Regular (400) and Medium (500) for architectural scale without excessive weight.

---

## 2. Body Typeface: Geist Sans
* **Role:** Editorial Body Copy, long-form paragraphs, and interface descriptions.
* **License:** **SIL Open Font License, Version 1.1 (OFL-1.1)**
* **Weights In Use:** Regular (400), Medium (500).

---

## 3. Utility / Metadata Typeface: Geist Mono
* **Role:** Strictly reserved for technical indices (`01 / 06`), technology names (`AWS / TERRAFORM`), and tiny registration stamps.
* **License:** **SIL Open Font License, Version 1.1 (OFL-1.1)**

---

## Zero Pirated or Unlicensed Fonts
* No pirated fonts (e.g., GT Walsheim commercial licenses) or unofficial clones are used or bundled.
* All fonts are genuinely open-source under the SIL Open Font License.
